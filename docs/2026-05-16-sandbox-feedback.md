# Sandbox Feedback Notes - 2026-05-16

## Context

This note summarizes feedback from real testing of the lightweight HTML sandbox demo. It avoids private family details and keeps the record focused on product behavior.

## Feedback

- The sandbox had read and repeat features, but no obvious pause control.
- Added words could not be deleted.
- Example sentences needed Chinese translations.
- Batch entry would make vocabulary testing faster than adding one word at a time.
- Vocabulary images were useful, but the visual style and sizing did not feel consistent.

## Fixed

- Added read / pause / resume controls for speech playback.
- Added delete support for vocabulary items.
- Added Chinese translation support for example sentences.
- Added batch word import using one word per line.

## Remaining Issues

- Image style and size consistency is still not fully solved.
- Batch import should be tested on tablet browsers.
- The future creative sandbox direction still needs exploration.
- Future voice/photo idea collection may be explored later.
