# English Study Sandbox Demo

This repository contains a lightweight HTML sandbox demo for quick English vocabulary, example sentence, and creative idea testing.

It is separate from the main Next.js reading app. The main app is intended for the fuller reading experience, while this sandbox stays small, static, and easy to change during early testing.

## Current Features

- Add individual vocabulary words
- Delete words
- Add example sentences with Chinese translations
- Read words and examples with browser speech controls
- Pause and resume speech when the browser supports it
- Batch import words from pasted text

## Open Locally

Open `index.html` directly in a browser.

No install step is required.

## Deployment

GitHub Pages publishes this repository as a static site.

Deployment is handled manually through normal git commits and pushes to the repo. There is no build step.

## Development Rules

- Keep this as single-file HTML/CSS/JS for now
- Do not add a framework
- Do not add a backend
- Do not add build tools
- Do not add external APIs unless explicitly approved
- Do not add private data, tokens, deployment secrets, or copyrighted content

## Known Issues

- Some vocabulary images are not yet visually consistent in style or size.
- The sandbox is intentionally simple and may not match the main app's final UI or architecture.
